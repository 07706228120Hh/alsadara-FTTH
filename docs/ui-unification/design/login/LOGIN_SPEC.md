# واجهة تسجيل الدخول — مواصفات التصميم الفخم ثلاثي الأبعاد

> الملف المستهدف: `lib/pages/login/premium_login_page.dart`
> المرجع البصري: `Login3D.dc.html` (سطح المكتب/آيباد) و `Login3DPhone.dc.html` (الهاتف) + الصور في هذا المجلد.
> ⚠️ شاشة مصادقة: أي تعديل يحتاج موافقة بشرية (CLAUDE.md). التعديل **واجهة فقط** — لا تغيير في `_login()` أو تخزين الحسابات أو استدعاءات API.

## الحالة الحالية (17-10-2026)
الملف مُرحَّل جزئياً إلى `Sd` (تعديل غير مُعتمد بتاريخ 16-10): خلفية متدرّجة + كرات ضوئية، صورة شخصية مربعة في الأعلى، بطاقة `SdCard` بيضاء مسطّحة عرضها 460، حقول Material، زر `SdButton`.

## التصميم الجديد
**سطح المكتب/آيباد أفقي (≥1024):** تقسيم — يمين: بطاقة الدخول مرفوعة (حافة سفلية 10px + ظل عميق + ميلان `rotateY(4°)` خفيف)، يسار: مشهد أيزومتري متحرّك (برج ألياف ← خطوط ضوئية متدفقة ← مبانٍ بمؤشرات ONT، ومكعّب درع عائم بشعار «ص») + عنوان «إدارة متكاملة لشبكتك / من البرج إلى المشترك» + 3 ميزات بمكعبات.
**آيباد عمودي (600–1023):** عمود واحد، مشهد مصغّر فوق البطاقة، عرض البطاقة 520.
**الهاتف (<600):** رأس بالشعار، مشهد مصغّر (ارتفاع ~230)، البطاقة تتداخل فوقه بـ −26px، عرض كامل بهامش 16.

### مكوّنات البطاقة (بالترتيب)
1. مكعّب قفل + «مرحباً بعودتك» + شارة اتصال **حيّة** (أخضر نابض / أحمر «غير متصل» / رمادي «جارٍ الفحص») مربوطة بنتيجة تحميل الشركات.
2. مفتاح مقسّم: «موظف شركة | مدير النظام» → «مدير النظام» يضبط `_selectedCompany` = العنصر id=1 ويخفي قائمة الشركات (نفس المنطق الحالي).
3. منتقي الشركة: حقل مرفوع بمكعب أيقونة + اسم + رمز.
4. اسم المستخدم، كلمة المرور (زر إظهار/إخفاء 44×44).
5. «تذكرني» → `SdToggle`، + «اتصال مشفّر».
6. الحسابات المحفوظة: شرائح (Chips) أفقية بحرف/رقم — الضغط يملأ الشركة والمستخدم (منطق `_selectedCredential` الحالي). لا تُعرض كلمات المرور.
7. زر «تسجيل الدخول» أساسي (60px، حافة 7px).
8. «إعداد الراوتر (أوفلاين)» ثانوي بأيقونة راوتر أيزومترية.
9. الإصدار + اسم المنصة.

### شاشة التحميل
مكعّب درع ثلاثي الأبعاد يدور (`Transform` + `Matrix4.rotationY`) + 3 مراحل: التحقق من البيانات ← تحميل الصلاحيات ← تحضير لوحة التحكم (مرحلة 1 أثناء `_isLoading`، 2–3 أثناء `_isNavigating`).

## الربط بـ Flutter
| العنصر | التنفيذ |
|---|---|
| المشهد الأيزومتري | `CustomPainter` جديد `SdLoginScene` في `lib/frontend/components/` بنفس رياضيات `IsoBox` في `network_quality/widgets/depth_3d.dart` + `AnimationController` واحد (تدفق الخطوط، طفو المكعب) — `RepaintBoundary`، يتوقف عند `TickerMode` off |
| البطاقة المرفوعة | `SdRaised(depth: 10)` + `Transform(Matrix4..setEntry(3,2,0.001)..rotateY(0.07))` على سطح المكتب فقط |
| المفتاح المقسّم | مكوّن جديد `SdSegmented` |

| الشرائح | `SdFilterChips` أو `Wrap` من `SdBadge` قابلة للضغط |
| المكعبات | `SdIconCube` |
| التخطيط | `SdAdaptive(phone:…, tablet:…, desktop: SdTwoPane(...))` |
