# توحيد واجهات تطبيق الصدارة — المرجع

مجلد التوثيق الخاص بمشروع توحيد الثيم وتحويل الواجهات إلى نمط ثلاثي الأبعاد متجاوب (هاتف/آيباد/سطح مكتب).

| الملف | المحتوى |
|---|---|
| `AUDIT.md` | تدقيق كل الشاشات (249): الغرض، مصدر الألوان، المشاكل، الأولوية، والمشتبه أنها ميتة |
| `screens_audit.json` | نفس التدقيق بصيغة بيانات |
| `MIGRATION_PLAN.md` | خطة الترحيل بالموجات مع مربعات إنجاز لكل شاشة، مواصفات الرئيسية الجديدة، والقرارات التي تحتاج موافقة |
| `PROGRESS_LOG.md` | سجل ما أُنجز شاشةً شاشة |
| `CLAUDE_CODE_PROMPT.md` | البرومبت الجاهز لتشغيل Claude Code على المهمة |
| `design/home_3d_reference.html` | التصميم المرجعي المعتمد للواجهة الرئيسية — يُفتح بأي متصفح (الفلاتر تعمل؛ صغّر النافذة لرؤية الهاتف) |
| `design/Home3D.dc.html` و `design/network_quality/*.dc.html` و `design/canvas.json` | مصادر لوحة التصميم الأصلية (Claude Design) للرئيسية وشاشات فحص الجودة الأربع |
| `screenshots/home_before_2026-10-16.jpg` | لقطة الواجهة الرئيسية الحالية قبل التحديث (للمقارنة) |
| `tools/scan.py` | سكربت الفحص الآلي (عدّ الألوان والثيمات والخطوط والاستيرادات لكل ملف): `python tools/scan.py src/Apps/CompanyDesktop/alsadara-ftth/lib` |

نظام التصميم نفسه في `src/Apps/CompanyDesktop/alsadara-ftth/lib/frontend/` (اقرأ README داخله).

الحالة (2026-10-16): نظام التصميم أُنشئ ولم يُفحص بـ flutter analyze بعد؛ لم تُرحَّل أي شاشة؛ لم يُعدَّل أي ملف قائم.

## خطة التنظيف الشامل
- `THEME_CLEANUP_PLAN.md` — المراحل والقواعد.
- `THEME_COMPLIANCE.md` — تقرير الالتزام (يُولَّد بـ `tools/theme_compliance.py`).
