# خطة تطوير ونشر وحدة «وكيل الساس» في منصة الصدارة

> الحالة: تمّ نقل تطبيق الوكلاء بالكامل تقريباً إلى تبويب «وكيل الساس» على فرع `feature/sas-agent-integration` (86 commit). هذه الوثيقة تحدّد المتبقّي، خارطة النشر، والقرارات.

---

## 1) ما أُنجز (مكتمل ومختبَر)

| الطبقة | المحتوى |
|---|---|
| **الباكند** | خدمة Python sidecar (SQLite، ~80 نقطة) + بوّابة .NET — عزل ثلاثي/user-scoped، fail-closed، حجب أسرار |
| **المشتركون** | تفاصيل + كل الإجراءات (تفعيل/تمديد/تغيير باقة/ترافيك/رصيد/حذف/استرداد) + تبويبات + نماذج + محلي/مباشر |
| **نظام الساس** | متصلون · وكلاء (إجراءات مالية) · سجلات · مالية KPI · صحة · مستكشف |
| **التقارير/الترخيص** | 10 تقارير + مجمّعة + ترخيص (تبويب مستقل) |
| **البلنك** | تصريح + مقاطعة (حكم) + مزامنة/اختبار الحسابات + تخزين محلي |
| **التذاكر** | نظام كامل (قائمة/إنشاء/محادثة/رد داخلي/حالة) |
| **الواتساب** | وحدة كاملة (app=wa.me + server + QR + قوالب + أزرار تجديد) |
| **العقارات** | NPN/IQ-Pin + QR + صورة دار + GPS + لصاقة PDF + ربط عقار↔اشتراكات |
| **الإعدادات + الداشبورد** | تبويب إعدادات + داشبورد مطابق (ملخّص/انتهاء/مالية/تصريح/دونات/تذاكر) |
| **الاختبارات** | .NET 100/100 · Python 62/63 (عزل/صلاحيات/عدم تسرّب) |

## 2) الميزات المتبقّية

| الميزة | الوصف | النطاق/التوصية | الجهد |
|---|---|---|---|
| **بوابة المشترك النهائي** | ربط/رصيد/فواتير/جلسات/تعبئة كرت/تغيير باقة+كلمة مرور للمشترك | **جمهور مختلف (المشترك لا الوكيل)** — الأنسب تطبيق/تبويب مشترك منفصل، أو نسخة «إدارة بوابة المشترك» للوكيل. الباكند جاهز (`portal_sas.py` + `sas_user_client`) | متوسط |
| **إدارة الوكلاء (أدمن)** | إصدار حسابات دخول للوكلاء + عرض شامل + البلنك عبر كل الوكلاء | **يتداخل مع إدارة مستخدمي الصدارة** — يُبنى فوق Users + SasAccounts القائمة + تجميع المقاطعة. لا نظام موازٍ | متوسط |

> كلاهما نطاق مختلف قليلاً عن «بروكسي الساس»؛ يُنفّذان كإضافة بعد تثبيت النواة الحالية.

## 3) خارطة النشر للإنتاج (المسار الحرج — يحتاج موافقتك)

| # | الخطوة | تفصيل | مخاطر |
|---|---|---|---|
| 1 | **تطبيق الهجرة** | `AddSasAgentModule` (إضافية بحتة: جدولان) على قاعدة الإنتاج + نسخة احتياطية + خطة تراجع (Down جاهز) | منخفض (إضافي) |
| 2 | **متغيّرات البيئة** | `SADARA_INTERNAL_API_KEY` (**تدوير المفتاح المكشوف** + تحديث n8n) · `SADARA_SAS_INTERNAL_SECRET` · `DataProtection:KeysPath` ثابت · `SasService:BaseUrl` | متوسط (تنسيق n8n) |
| 3 | **خدمة الساس (sidecar)** | نشر `modules/sas-agent/service` كـ systemd على 127.0.0.1:8100 (venv + متغيّرات) — غير مكشوفة للإنترنت | منخفض |
| 4 | **الواتساب (اختياري)** | `whatsapp-server`: npm install (Node محمول) + systemd + **مسح QR مرّة** — أو الاكتفاء بنمط `app` | متوسط |
| 5 | **بناء/نشر .NET** | `dotnet publish` + SCP إلى VPS + `systemctl restart sadara-api` | منخفض |
| 6 | **بناء/نشر Flutter** | **إعادة `isProduction=true`** في `api_config.dart` + `sadara_api_service.dart` أولاً · `flutter build windows` + Inno/تحديث تلقائي | منخفض |
| 7 | **مزامنة أولية** | لكل وكيل: زر «مزامنة» لملء المشتركين المحليين | منخفض |

**ملاحظة:** كل عمليات النشر على الإنتاج تتطلّب موافقتك الصريحة (قواعد الصدارة الذهبية).

## 4) القرارات المعلّقة

| القرار | الأثر | التوصية |
|---|---|---|
| **تدوير `Security:InternalApiKey`** | مكشوف سابقاً في المستودع؛ يفتح منفذ الأدمن | تدوير + ضبط env + تحديث n8n قبل النشر (إلزامي) |
| **`Tenancy:EnforceIsolation`** | معطّل افتراضياً؛ العزل العام غير مفعّل (وحدتنا تعزل صراحةً فلا تتأثّر) | تفعيله بعد backfill لبيانات CompanyId الفارغة — قرار تشغيلي منفصل |
| **`RequirePermission` fail-open للنظام الثاني** | مستخدم بعمود صلاحيات فارغ يُمنح ميزات النظام الثاني | وحدتنا تستخدم `failClosed:true` فمحميّة؛ يُنظر بجعلها fail-closed عامة لاحقاً |

## 5) الديون التقنية والجودة

- **بناء Flutter ويندوز**: يعلّق عشوائياً على `cppwinrt` (ملحق permission_handler) — إعادة المحاولة تنجح؛ يُنظر بترقية/استبدال الملحق أو تثبيت إصدار cppwinrt مستقر. تجنّب الإنهاء القسري لـ dart أثناء البناء.
- **CI**: إضافة `dotnet test` (Sadara.Integration.Tests) + `pytest` (خدمة الساس) لـ GitHub Actions.
- **العقارات**: أُصلحت 3 عيوب (سرّ lazy · رفض حقول فارغة · حدّ صورة). راجع `sas_premises.py`.
- **عقد /dashboard**: خدمة Python تعيد كائناً؛ .NET يمرّره خاماً؛ الواجهة تحلّل بمرونة — سليم.
- **مصدر الحقيقة للمشترك**: `api.ftth.iq` (الصدارة) مقابل SAS4 (الوحدة) — التوفيق عبر مصدر منفصل لكل تبويب؛ لا كتابة متبادلة.
