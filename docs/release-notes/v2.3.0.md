## ✨ أبرز التحسينات — نظام المهام

- **لوحة إدارة المهام أصبحت من الخادم:** بطاقات الحالة وتوزيع الفنيين تُحسب الآن على الخادم عبر endpoint تجميع واحد بدل تحميل آلاف السجلات في التطبيق — **أرقام دقيقة دائماً وأداء أسرع**.
- **إصلاح ظهور المهام:** المهام **المرفوضة** كانت تظهر خطأً ضمن «المفتوحة» — الآن تُصنَّف صحيحاً ضمن «الملغية».
- **توحيد ألوان الحالات** عبر كل شاشات المهام (كانت «قيد التنفيذ» تظهر بالأزرق في شاشة الموارد البشرية بدل البرتقالي).
- **عرض فوري للوحة** عبر تخزين مؤقت خفيف للملخّص (يُعرض آخر ملخّص فوراً ثم يُحدَّث).
- **تطبيع أسماء الفنيين** لمنع اختفاء مهام بسبب اختلاف المسافات في الاسم.

## 📱 تحسينات الواجهة والهاتف

- إصلاح تجاوز العناصر (overflow) على الشاشات الصغيرة في صفحة المتابعة وشاشة مهام الموارد البشرية.
- أسهم الرجوع تُعرض باتجاه صحيح في الواجهة العربية (RTL).
- تكبير مناطق اللمس للأزرار الصغيرة (≥44px).
- الشريط السفلي أوضح على الهاتف (خط أكبر وتسميات أقصر).
- عرض المبالغ بفواصل آلاف (مثال: 1,500,000 بدل 1500000).
- مكوّنات واجهة موحّدة (بطاقات/خلايا معلومات/رقائق فلترة) لاتساق أفضل.

## 🔐 إصلاح الأجهزة الجديدة — واتساب

- **تضمين وتثبيت شهادة جذر Let's Encrypt (ISRG Root X1)** ضمن المُثبِّت: يُصلح فشل قوالب تجديد واتساب عبر n8n على أجهزة Windows الجديدة التي تنقصها الشهادة (`CERTIFICATE_VERIFY_FAILED`).
- رسائل خطأ أوضح عند تعذّر الاتصال بـ n8n (تُظهر سبب العطل).
