# هيكلية «تطبيق الوكلاء» (Aluklaa)

منتج مستقل من ثلاث طبقات: عميل Flutter · حزمة مشتركة · باكند FastAPI واحد.

## الطبقات

```
┌──────────────────────────────────────────────────────────────┐
│  العميل (Flutter)  —  frontend/lib                            │
│    main.dart  →  توجيه حسب نوع الحساب:                        │
│      • وكيل  → AppShell(الوكيل): لوحتي · مشتركيّ · نظام SAS · التذاكر · تصريحي · الإعدادات
│      • أدمن → AppShell(الأدمن): الوكلاء · التذاكر · الإعدادات   │
└───────────────┬──────────────────────────────────────────────┘
                │ يستورد
┌───────────────▼──────────────────────────────────────────────┐
│  الحزمة المشتركة  —  packages/platform_core                   │
│    StaffApi (عميل REST) · Session · نظام التصميم (theme/brand) │
│    شاشات: الدخول · التذاكر · SAS (config/panel/subscriber)     │
└───────────────┬──────────────────────────────────────────────┘
                │ HTTP (API_BASE)
┌───────────────▼──────────────────────────────────────────────┐
│  الباكند  —  backend/app  (FastAPI، باكند واحد)               │
│    api/       auth · companies(SAS proxy) · portal · subscriber · tickets · agents · users · audit
│    services/  sas_sync · otp · tickets · agents · audit         │
│    integrations/sas_client.py  →  SAS4 (Snono)                 │
│    core/      auth · security                                   │
│    قاعدة البيانات: SQLite (محلي) أو Postgres (سحابي)           │
│    [محفوظ/غير مُفعَّل]: devices · onts · provisioning · snmp · troubleshoot · monitoring · gov · transit · dfos · ai
└───────────────┬──────────────────────────────────────────────┘
                │ HTTPS (بروكسي معزول بالنطاق)
┌───────────────▼──────────────────────────────────────────────┐
│  خادم SAS4 الخاص بمزوّد الوكيل (خارجي — ليس جزءاً من المنصّة)   │
└──────────────────────────────────────────────────────────────┘
```

## تدفّق طلب نموذجي (عرض مشتركي الوكيل)

1. الوكيل يفتح «مشتركيّ» → `StaffApi.subscribers()` → `GET /api/companies/subscribers`.
2. الباكند يتحقّق من التوكن، يحصر النطاق (company_id + agent)، ويستدعي SAS عبر `sas_client` (بروكسي).
3. تُعاد القائمة معزولةً على مشتركي هذا الوكيل فقط.

## العزل متعدّد المستأجرين

يفرضه الباكند من توكن الجلسة: وكيل يرى نطاقه · أدمن (regulator) يرى الكل. لا منطق صلاحيات في العميل.

## أنماط النشر

- **ويندوز محلي**: `backend.exe` (PyInstaller) + SQLite في مجلد قابل للكتابة (`ALUKLAA_DATA_DIR`) — يُحزَّم في `AluklaaSetup.exe`.
- **سحابي/هاتف**: باكند مستضاف + Postgres، والعميل (ويندوز/هاتف) يتصل عبر `API_BASE=https://…`.
