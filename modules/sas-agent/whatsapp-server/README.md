# خادم واتساب المحلي — تطبيق الوكلاء

خادم **Node.js** يتيح **الإرسال الجماعي الآلي المجاني** عبر واتساب، بمكتبة
[`whatsapp-web.js`](https://github.com/pedroslopez/whatsapp-web.js). هذا هو **النمط `server`**
في وحدة واتساب (النمط الافتراضي `app` عبر wa.me لا يحتاجه إطلاقاً).

## مدمج ومُدار تلقائياً (لا تشغيل يدوي)

- **يُشحن جاهزاً مع المُنصِّب** داخل `{app}\whatsapp-server` (يتضمّن Node محمولاً + الاعتماديات).
- **يُشغّله التطبيق تلقائياً** (مخفيّاً، بلا نافذة) عند تفعيل نمط «خادم محلي» أو عند الإقلاع
  إن كان محفوظاً — عبر `WaServerLauncher` في التطبيق. ويُوقفه عند إغلاق التطبيق.
- **يستخدم Edge/Chrome الموجود في ويندوز** (لا تنزيل Chromium ~300MB).
- **بيانات الجلسة** في `%LOCALAPPDATA%\Aluklaa\whatsapp` — **تُحذف مع إلغاء تثبيت التطبيق**.

المستخدم لا يفعل شيئاً سوى: **الإعدادات ← واتساب ← «خادم محلي» ← ربط ← مسح QR** مرّة واحدة.

## تحضير الحزمة (مرّة على جهاز البناء فقط)

قبل بناء المُنصِّب، شغّل مرّة لتنزيل Node المحمول وتثبيت الاعتماديات:

```powershell
powershell -ExecutionPolicy Bypass -File prepare_bundle.ps1
```

ينشئ `runtime\node.exe` + `node_modules\` (مع تخطّي تنزيل Chromium). بعدها يحزم
`aluklaa.iss` المجلد كاملاً. الملفات الكبيرة (`runtime/`, `node_modules/`) خارج git.

## التشغيل اليدوي (تطوير فقط)

```bat
start_whatsapp_server.bat      :: يثبّت الاعتماديات إن لزم ثم يشغّل ظاهراً
:: أو
npm start
```

يستمع على `http://127.0.0.1:3100` (محلي فقط، لا يُعرَّض للشبكة).

## واجهة HTTP (يستهلكها التطبيق)

| الطريقة | المسار | الغرض |
|---|---|---|
| GET | `/` | فحص حياة الخادم |
| GET | `/status/:tenant` | حالة الجلسة `{ state, phone }` |
| POST | `/session/:tenant` | إنشاء/تهيئة الجلسة (يبدأ QR) |
| DELETE | `/session/:tenant` | قطع الجلسة وحذفها |
| GET | `/qr-image/:tenant` | رمز QR كصورة PNG |
| POST | `/send/:tenant` | إرسال رسالة `{ phone, message }` |
| POST | `/send-bulk/:tenant` | دفعة `{ messages[], delaySeconds }` |
| GET | `/send-bulk/:tenant/status` | حالة الدفعة الجارية |
| POST | `/send-bulk/:tenant/cancel` | إلغاء الدفعة |

`:tenant` = معرّف الجلسة (التطبيق يستخدم `default`). البنية تدعم تعدّد المستأجرين مستقبلاً.

## البنية (مجزّأة تحت `src/`)

`config` (منفذ/مسارات/كشف المتصفّح) · `browser` (كشف Edge/Chrome) · `phone` (تطبيع عراقي) ·
`session` (دورة حياة العميل + QR + إعادة اتصال) · `sender` (إرسال فردي/دفعة) · `routes` (HTTP).

## ملاحظات

- **حماية من الحظر:** فاصل افتراضي 5ث بين الرسائل (حدّ أدنى 3). قناة غير رسمية — لا تُفرِط.
- **الترقية مستقبلاً إلى Meta الرسمي (نمط `api`)** تُنفَّذ في التطبيق (`ApiSender`) ولا علاقة لها بهذا الخادم.
