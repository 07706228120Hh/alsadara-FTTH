# الترقيم الاحترافي للمنازل عبر QGIS — نظام NAS-IQ

هذا المجلد يمكّنك من **ترقيم المنازل آلياً** داخل QGIS بنفس خوارزمية المنصّة (النظام
الوطني للعنونة الرقمية NAS-IQ)، ثم إنتاج **لوحات ورموز QR** جاهزة للطباعة.

## ما الذي يتم آلياً؟

| المُخرَج | الأداة | يحتاج |
|---|---|---|
| **IQ-Pin** (رمز شبكي ~1م) | `nas_iq_numbering.py` | إحداثيات المبنى فقط |
| **NPN** (رقم العقار 11 خانة + Luhn) | `nas_iq_numbering.py` | كود المحافظة + تسلسل |
| **رقم الدار** (فردي/زوجي على الشارع) | المنصّة (`/gis-layers/{id}/number`) أو QGIS | طبقة محاور شوارع |
| **لوحة + رمز QR** | QGIS Print Layout + **Atlas** | حقل `npn` |
| **مخططات لكل بلوك** | QGIS Atlas (تغطية = طبقة البلوكات) | — |

## الخطوات

### 1) الترقيم (NPN + IQ-Pin)
- **الأسهل — عبر المنصّة**: ارفع طبقة المباني (GeoJSON/KML) في تبويب «الخريطة» → لوحة
  «المجموعات» → زرّ **#** على الطبقة → اختر المحافظة (وطبقة الشوارع اختياراً لرقم الدار)
  → «ترقيم». النتائج تُكتب في خصائص الطبقة وتظهر عند النقر على المبنى.
- **أو داخل QGIS مباشرة**: افتح `nas_iq_numbering.py` في *Python Console → Editor*،
  عدّل `GOV_CODE` و`START_SEQ`، فعّل طبقة المباني، ثم **Run**. تُضاف الحقول
  `npn, npn_disp, iqpin, iqpin_disp`. صدّر GeoJSON (*Export → Save Features As*) وارفعها.

> **تفادي تكرار NPN**: `START_SEQ` يجب أن يتابع من آخر رقم استُخدم لكل محافظة. المنصّة
> تدير هذا آلياً عبر عدّاد `NpnCounter`؛ في QGIS تابِعه يدوياً بين الدفعات.

### 2) اللوحة الفيزيائية + رمز QR (QGIS Atlas)
1. أنشئ *Print Layout* جديداً بمقاس اللوحة (مثلاً 15×10 سم).
2. أضِف عنصر **QR Code** (QGIS ≥ 3.36: *Add Item → Add QR code*) واربطه ببيانات محسوبة
   (Data Defined): التعبير
   `'https://a.iq/' || npn_disp`  (رابط صفحة السجل العامّة — الموقع + العنوان الوصفي فقط).
3. أضِف تسمية نصّية كبيرة: `[% npn_disp %]` وأخرى أصغر: `IQ-Pin [% iqpin_disp %]`.
4. فعّل **Atlas** (*Atlas → Generate an atlas*) وطبقة التغطية = طبقة المباني (أو البلوكات)،
   ثم *Export Atlas as Images/PDF* — تحصل على **لوحة لكل مبنى** تلقائياً.

### 3) المخطط لكل بلوك
اجعل تغطية Atlas = طبقة «مناطق العد/البلوكات» (18 خانة من التعداد)، مع تسمية المباني
بـ `npn_disp` — تحصل على صفحة خريطة لكل بلوك جاهزة للطباعة والتدقيق الميداني.

## المطابقة والمعايير
- الخوارزمية مُتحقَّقة مقابل أمثلة الدراسة الأربعة (التحرير→`8L8-L86-5FMT`، البصرة، أربيل،
  الموصل) وضمن اختبارات المنصّة (`tests/test_addressing.py`، `tests/test_map.py`).
- تتوافق مع RFC 5139 / UPU S42 / ISO 19160 كما في الدراسة (`ADDCODE = NPN`).

راجع الدراسة الكاملة: «النظام الوطني للعنونة الرقمية في العراق» (NAS-IQ).
