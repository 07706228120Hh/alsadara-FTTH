# Sadara Platform — team lessons (append newest at the bottom: date, what went wrong, the rule to follow)

- 2026-10-15 — network_quality results page went blank after a scan. Root cause: a `Row(crossAxisAlignment: CrossAxisAlignment.stretch)` placed inside a `Column` (quality_results_page `_buildPerformance`, the two download/upload `BigStatTile` cards) → unbounded cross-axis height → `RenderBox was not laid out (hasSize)` cascading to Null-check + mouse_tracker assertions and an empty body. Rule: never use `CrossAxisAlignment.stretch` on a `Row` whose height is unbounded (inside a Column/ListView); use `start`/`center`, or wrap in `IntrinsicHeight` if equal heights are required. A clean `flutter analyze` does NOT catch layout errors — pump the screen in a `testWidgets` and assert `tester.takeException()` is null before calling a UI change done.
- 2026-10-15 — `webview_windows` renders a NATIVE surface composited ON TOP of all Flutter widgets; you cannot hide it behind a Flutter layer (an opaque Container over it does nothing), and a full-screen `Webview` left mounted covers later routes + crashes on pointer packets. Rule: for silent/headless scraping, mount the `Webview` only while actively reading, at 1×1 in a corner, wrapped in `IgnorePointer`; the controller's loadUrl/executeScript still work.

## 2026-10-29 — Flutter Web: مُسجِّل إضافات مخبوء ناقص + تحقّق SW
- **العطل**: «تعذّر تشغيل الفيديو» على ramzbot.com (CitizenWeb). الخطأ الحقيقي `UnimplementedError: init() has not been implemented` = `video_player_web` غير مسجَّل.
- **الجذر**: `flutter build web` أعاد استخدام `.dart_tool/flutter_build/<hash>/web_plugin_registrant.dart` مخبوء وناقص (بلا video_player/url_launcher المضافَين حديثاً). يعمل في `flutter run` ويفشل في البناء المنشور. **الحل: `flutter clean` قبل كل `flutter build web`.**
- **عطل ثانٍ مُقنِّع**: Marquee ينادي `ScrollController.jumpTo` قبل جاهزية أبعاد ScrollView ⇒ «Null check» كل إطار يكسر خط الإطارات ويمنع تهيئة الفيديو. حارس: `if (!pos.hasPixels || !pos.hasContentDimensions) return;`. و`late final AnimationController` يُنشَأ كسولاً في dispose ⇒ «deactivated ancestor»؛ اجعله nullable.
- **درس تحقّق**: بعد نشر Flutter Web، service worker يخدم النسخة القديمة؛ تحقّق Playwright يحتاج `unregister()` + مسح `caches` ثم إعادة تحميل، وإلا تفحص بناءً قديماً وتظنه فشلاً جديداً. تحقّق الخادم مباشرة بـ `curl .../version.json`.
- **درس**: `flutter analyze` نظيف لا يكشف أخطاء runtime (tickers/scroll/dispose/تسجيل إضافات). افحص فعلياً عبر Playwright.
