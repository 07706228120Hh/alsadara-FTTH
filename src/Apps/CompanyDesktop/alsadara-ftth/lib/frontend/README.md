# نظام تصميم الصدارة الموحّد — `lib/frontend/` (sd)

مجلد جديد ومستقل. **لا يستورده أي ملف قديم ولا يغيّر شيئاً في المشروع** حتى نقرّر
ترحيل شاشة بعينها. كل شاشة تُرحَّل تستورد `frontend.dart` فقط.

## البنية
```
frontend/
  frontend.dart              # تصدير موحّد (import واحد)
  tokens/
    sd_colors.dart           # الألوان + مجموعات الأقسام (SdGroup) + الحالات (SdStatus)
    sd_metrics.dart          # المسافات SdSpace، الأقطار SdRadius، العمق SdDepth، الحركة SdMotion
    sd_typography.dart       # أنماط النص SdText (Cairo، أصغر حجم 11.5)
    sd_responsive.dart       # التجاوب: context.sd، SdAdaptive، SdTwoPane، نقاط الفصل
  theme/
    sd_theme.dart            # SdTheme.light() + SdTheme.scope(child) + امتداد SdTokens
  components/
    sd_raised.dart           # SdRaised (سطح بارز قابل للضغط) + SdButton
    sd_cube.dart             # SdIconCube (مكعّب أيقونة مجسّم + شارة)
    sd_basics.dart           # SdBadge، SdStatusChip، SdSectionHeader، SdFilterChips، SdToggle، SdCard، SdInfoRow، SdEmptyState
    sd_app_bar.dart          # SdAppBar (نيلي بحافّة بارزة) + SdAppBarAction (أيقونة + اسم)
    sd_menu_tile.dart        # SdMenuTile (بلاطة قسم) + SdTileGrid (شبكة متجاوبة)
    sd_stat_pedestal.dart    # SdStatPedestal (مؤشّر على عمود متساوي القياس)
    sd_page.dart             # SdPage (هيكل صفحة: RTL + ثيم + عرض أقصى)
  preview/
    sd_gallery_page.dart     # معرض كل المكوّنات للمراجعة (غير مربوط بأي مسار)
```

## قواعد الاستخدام
1. **لا ألوان مكتوبة يدوياً** (`Color(0x…)` أو `Colors.red`) داخل الشاشات المرحَّلة —
   استخدم `SdColors` و`SdGroup.x.tone` و`SdStatus.x.tone`. لون جديد؟ أضفه في `sd_colors.dart`.
2. **لون لكل مجموعة لا لكل زر**: الميدان تركوازي، الإدارة نيلي، التواصل برتقالي،
   المنصّات بنفسجي، الأدوات رمادي.
3. **شريط علوي واحد**: `SdAppBar` في كل الشاشات (لا تدرّجات ولا ألوان خاصة بالقسم).
4. **أصغر خط 11.5**، والأزرار ≥ 44px ارتفاعاً.
5. **العمق ثلاثي الأبعاد** عبر `SdDepth` فقط (حافّة سفلية صلبة + توهّج)، لا ظلال عشوائية.
6. هوية واتساب (`SdColors.whatsapp`) للأيقونة/الشعار فقط، لا للشريط أو الخلفية.

## ترحيل شاشة (خطوات)
1. استبدل `Scaffold` + `AppBar` بـ `SdPage(appBar: SdAppBar(title: '...'), body: ...)`.
2. استبدل البطاقات بـ `SdCard`، والأزرار بـ `SdButton`، والشارات بـ `SdStatusChip`/`SdBadge`.
3. احذف الثوابت اللونية المحلية في الملف وما يقابلها من hex.
4. لا تغيّر المنطق (الخدمات، الصلاحيات، التنقّل) — الواجهة فقط.
5. `flutter analyze` ثم اختبار يدوي للشاشة.

## الاعتماد الكامل لاحقاً
بعد ترحيل الشاشات الأساسية وبموافقة صريحة: `theme: SdTheme.light()` في `main.dart`
بدل `AppTheme.lightTheme`. حتى ذلك الحين يبقى `SdTheme.scope` محصوراً بالشاشات المرحَّلة.

## التجاوب (الهاتف · الآيباد · سطح المكتب) — إلزامي لكل شاشة
نقاط الفصل نفسها في المشروع: **هاتف < 600 ≤ آيباد < 1024 ≤ سطح مكتب**.

| العنصر | الهاتف | الآيباد | سطح المكتب |
|---|---|---|---|
| حشو الصفحة الجانبي | 14 | 20 | 24 |
| بلاطات الأقسام `SdMenuTile` | عمودية مدمجة، عمودان | أفقية، 2–3 أعمدة | أفقية، حتى 4 أعمدة |
| المؤشرات `SdStatPedestal` | عمود واحد، بطاقة أقصر | 2–3 أعمدة | 3 أعمدة |
| أزرار الشريط العلوي | أيقونة + تلميح | أيقونة + تلميح | أيقونة + اسم |
| الفلاتر `SdFilterChips` | صف واحد يمرَّر أفقياً | التفاف | التفاف |
| قائمة + تفاصيل `SdTwoPane` | متراصّتان (أو شاشة مستقلة) | جنباً إلى جنب في الوضع الأفقي (≥ 900) | جنباً إلى جنب |
| أهداف اللمس | 48 | 48 (لمس) | 44 |
| تأثيرات المرور (ميل/رفع) | معطّلة | معطّلة على الأجهزة اللمسية | مفعّلة |

القواعد:
- استخدم `context.sd` (`isPhone`، `gutter`، `pick(...)`) بدل أرقام ثابتة أو `MediaQuery` مباشرة.
- لا جداول عريضة على الهاتف: حوّلها لبطاقات، أو ضعها داخل تمرير أفقي.
- لا نص أصغر من 11.5 على أي جهاز (لا نصغّر الخط على الهاتف — نقلّل المحتوى بدلاً منه).
- احترم حواف النظام (`SdPage` يضيف SafeArea تلقائياً).
- **اختبار كل شاشة بأربعة عروض قبل اعتمادها:** 390 (هاتف)، 820 (آيباد عمودي)، 1180 (آيباد أفقي)، 1440 (سطح مكتب).

## قاعدة الإطار الأسود (17-10-2026)
كل حقل وبطاقة وزر يحمل إطاراً أسود: `border: SdOutline.all` أو `side: SdOutline.side` (التركيز: `SdOutline.focus`). لا تستخدم حدوداً رمادية أو بدون حدود لهذه العناصر.

## القائمة الجانبية
أي صفحة فيها قائمة تنقّل تستخدم `SdNavShell` (أو `SdSideNav` / `SdSideNav.drawer`). ممنوع بناء Drawer أو Sidebar يدوي. قائمة واحدة للعناصر تُستخدم للهاتف والآيباد وسطح المكتب.
