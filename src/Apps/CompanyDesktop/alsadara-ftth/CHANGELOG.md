# سجل التغييرات - Changelog

## [v2.3.0+305] - 2026-08-01

> الإصدار السابق: `v2.2.25+304`. التوزيع: مُثبِّت Inno Setup ثم GitHub Releases (`07706228120Hh/alsadara-FTTH`) ثم تحديث تلقائي.
> ملاحظة: المقارنة تعتمد على `major.minor.patch` فقط؛ الانتقال `2.2.25 -> 2.3.0` يُطلق التحديث تلقائياً (جزء الـ build يُتجاهل في المقارنة).

### ✨ ميزات جديدة — نظام المهام

- **لوحة إدارة المهام تُحسب على الخادم**: بطاقات الحالة وتوزيع الفنيين تُجمَّع الآن عبر endpoint خادمي واحد (`GET /api/servicerequests/summary`) بدل تحميل آلاف السجلات في التطبيق — أرقام أدق وأداء أسرع. يعمل التطبيق مع fallback عميلي إن تعذّر الملخّص.
- **عرض فوري للوحة**: تخزين مؤقت خفيف للملخّص (يُعرض آخر ملخّص فوراً ثم يُحدَّث في الخلفية).
- **تطبيع أسماء الفنيين**: منع اختفاء مهام بسبب اختلاف المسافات في الاسم.
- **مكوّنات واجهة موحّدة**: بطاقات وخلايا معلومات ورقائق فلترة موحّدة عبر شاشات المهام لاتساق أفضل.

### 🐛 إصلاحات

- **تصنيف المهام المرفوضة**: كانت المهام المرفوضة تظهر خطأً ضمن «المفتوحة» — الآن تُصنَّف صحيحاً ضمن «الملغية».
- **توحيد ألوان الحالات** عبر كل شاشات المهام (كانت «قيد التنفيذ» تظهر بالأزرق في شاشة الموارد البشرية بدل البرتقالي).
- إصلاح تجاوز العناصر (overflow) على الشاشات الصغيرة في صفحة المتابعة وشاشة مهام الموارد البشرية.
- تصحيح اتجاه أسهم الرجوع في الواجهة العربية (RTL).
- عرض المبالغ بفواصل الآلاف (مثال: `1,500,000` بدل `1500000`).

### 📱 تحسينات الواجهة والهاتف

- تكبير مناطق اللمس للأزرار الصغيرة (‏≥44px).
- الشريط السفلي أوضح على الهاتف (خط أكبر وتسميات أقصر).

### 🔐 إصلاح الأجهزة الجديدة — واتساب

- **تضمين وتثبيت شهادة جذر Let's Encrypt (ISRG Root X1)** ضمن المُثبِّت: يُصلح فشل قوالب تجديد واتساب عبر n8n على أجهزة Windows الجديدة التي تنقصها الشهادة (`CERTIFICATE_VERIFY_FAILED`).
- رسائل خطأ أوضح عند تعذّر الاتصال بـ n8n (تُظهر سبب العطل).

### 🔒 أمن

- تقييد قسم «التحصيلات» (collections) بصلاحية `accounting.collections/view`.

### 🧹 صيانة

- إزالة كود Firestore غير المستخدم للمهام.
- التحقق من بصمة شهادة الجذر (SHA-256) في خط بناء CI قبل بناء المُثبِّت.

### 📝 ملاحظات

- **غير مشمول**: المرحلة 2 (تطبيع أعمدة القسم/الفني) — الكود جاهز لكن غير منشور؛ الإصدار الحالي يعمل عبر الـ endpoint الحيّ.
- المُثبِّت غير موقّع (Authenticode) — متّسق مع كل الإصدارات السابقة.
- **ملاحظة أمنية مفتوحة (غير حاجبة، قائمة مسبقاً)**: `RequirePermissionAttribute` بسلوك fail-open — موثّقة للمتابعة، غير مُدخَلة بهذا الإصدار.

## [v1.4.0] - 2025-02-21

### ✨ ميزات جديدة

- **نظام المحاسبة المتكامل**: لوحة محاسبة محدّثة مع 8 بطاقات إحصائية
- **كشف حساب العملاء**: صفحة كشف حساب جديدة مع فلاتر تاريخ وملخص
- **ربط المشغلين FTTH**: صفحة ربط مشغلي FTTH بالموظفين مع عرض الأرصدة والأدوار
- **مراقبة الأموال**: صفحة جديدة لمراقبة حركة الأموال
- **حسابات التفعيلات**: لوحة تفصيلية لحسابات تفعيلات FTTH
- **إدارة الوكلاء المحدّثة**: تحسين واجهة إدارة الوكلاء مع شريط جانبي محدّث

### 🔧 تحسينات

- تحديث الشريط الجانبي للمحاسبة (القيود المحاسبية، الرواتب، الإحصائيات)
- دمج المصروفات والإيرادات في نافذة واحدة
- تحسين عرض رصيد القاصة (حساب 11101) مع fallback ذكي
- إعادة تسمية مشغلو FTTH إلى حسابات التفعيلات
- تحسين أداء تحميل البيانات بالجلب المتوازي

### 🐛 إصلاحات

- إصلاح عرض رصيد القاصة الذي كان يظهر صفر
- إصلاح صفحة ربط المشغلين لعرض مشغلي FTTH بدلاً من الموظفين
- إصلاح تعارض TextDirection مع مكتبة intl
