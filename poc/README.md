# النموذج الأوّلي للمعمارية الموزّعة (Proof of Concept)

نماذج معزولة تثبت قلب المعمارية الموزّعة (راجع `docs/architecture/ADR-001-distributed-multi-tenant.md`).

> ⚠️ **معزول تماماً**: تخزين في الذاكرة فقط، لا قاعدة بيانات، **لا يمسّ الإنتاج ولا نظام الدخول الحالي**. للتجربة والإثبات فقط.

## المكوّنات الثلاثة

| المجلد | يمثّل | المنفذ |
|--------|-------|--------|
| `rs256-auth/` | إثبات مبدأ: توقيع مركزي / تحقق محلي (سطر أوامر) | — |
| `identity-gateway/` | **بوابة الهوية** (المركز/هوستنكر) — تُصدر البطاقات | 5080 |
| `company-node/` | **العقدة المحلية** (حاسبة الشركة) — تتحقق وتطبّق الصلاحيات | 5090 |

## كيف يعمل (الدائرة الكاملة)

```
مدير الشركة → [بوابة الهوية 5080] يتحقق ويُصدر بطاقة RS256 (24 ساعة)
                     │ (تنشر المفتاح العام عبر /.well-known/jwks.json)
                     ▼
البطاقة → [العقدة المحلية 5090] تتحقق منها ذاتياً بالمفتاح العام
          وتطبّق الصلاحيات على العمليات المحلية (بلا سؤال المركز لكل طلب)
```

## التشغيل والفحص

```bash
# 1) شغّل بوابة الهوية (المركز)
cd poc/identity-gateway && dotnet run -c Release      # http://127.0.0.1:5080

# 2) في نافذة أخرى: شغّل العقدة المحلية (تجلب المفتاح العام من البوابة عند الإقلاع)
cd poc/company-node && dotnet run -c Release          # http://127.0.0.1:5090
```

### أمثلة الطلبات

```bash
G=http://127.0.0.1:5080; N=http://127.0.0.1:5090

# تسجيل دخول → بطاقة
curl -X POST $G/auth/login -H "Content-Type: application/json" \
  -d '{"username":"nour_admin","password":"P@ssw0rd!"}'

# مدير النظام ينشئ شركة (أسماء عربية: أرسلها عبر ملف UTF-8 بـ --data-binary @file)
curl -X POST $G/admin/companies -H "X-Admin-Key: super-admin-demo-key" \
  -H "Content-Type: application/json" -d '{"name":"AlFajr Telecom"}'

# استخدام البطاقة على العقدة المحلية
TOKEN=... # access_token من تسجيل الدخول
curl $N/subscribers -H "Authorization: Bearer $TOKEN"
```

| نشر المفتاح العام عبر jwks.json | ✅ |
| العقدة تحمّل المفتاح العام وتتحقق ذاتياً (بلا سؤال المركز) | ✅ |

| دعم الأسماء العربية | ✅ |

## بيانات تجريبية مبدئية

- شركة: `شركة النور للإنترنت` — مدير: `nour_admin` / `P@ssw0rd!` (كل الصلاحيات).
- مفتاح مدير النظام (تجريبي): `super-admin-demo-key`.

## القيود (نموذج أوّلي — ليس للإنتاج)

- تخزين في الذاكرة (يضيع عند إعادة التشغيل)، لا تشفير نقل (HTTPS)، مفتاح مدير النظام ثابت.
- مفتاح المركز يُولَّد ويُحفظ في `identity-gateway/bin/.../keys/` (للإنتاج: secret store/HSM).
- الإنتاج يتطلب: قاعدة بيانات، HTTPS، إدارة مفاتيح آمنة، تدوير المفاتيح، ومروراً على security-auditor.
